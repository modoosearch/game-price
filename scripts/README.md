# 바로템 시세 푸시 스크립트

**게임머니 카테고리**에서 **거래완료물품** 선택 시, 사이트가 **서버 전체**를 한 목록으로 보여 주므로, **서버별로 URL을 돌지 않고** 그 **한 페이지(전체) URL만** 페이지네이션으로 수집합니다.

## 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 확장 설치
2. `barotem-push.user.js` 내용 복사 → Tampermonkey 새 스크립트로 붙여넣기 → 저장
3. 바로템 **아무 페이지나** 한 탭만 열어두면 됨

## 중계 서버 주소

스크립트 상단 `API_BASE` 를 커스텀 도메인으로 바꾸면 됩니다.

```javascript
var API_BASE = 'https://gameprice.onrender.com';  // 또는 https://aden.infosearch.kr
```

## 파싱 정보 (항목당)

- **서버명**: 각 게시물 블록의 `div > div > span` (예: 데포로쥬) → 서버코드와 매핑
- **거래량**: `ul.di_no_i` 다음 `span` → `[수량 부족]`이면 분할(0), 아니면 거래 수량
- **날짜·시간**: 마지막 `div` (예: 02월 25일 / 04:46)
- **만당 가격**: `span` "만당 N원" 추출

## 동작

- **한 URL만 사용**: `display=3`(거래완료) + **opt1 비움** = 서버 전체 한 목록
- **당일 1회 풀스캔**: 1~N페이지 전부 수집 후 서버별로 묶어 푸시
- **이후**: 1페이지만 수집해 서버가 id 기준 병합(추가분만 반영)
