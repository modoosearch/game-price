============================================
  기존 호스팅 test 폴더에 테스트하는 방법
============================================

[방법 1] 호스팅이 Node.js를 지원할 때
--------------------------------------
1. test 폴더에 이 프로젝트 전체 업로드
   (package.json, server 폴더, client 폴더 등 전부)

2. 호스팅 제공처의 "Node 앱 실행" 또는 SSH 접속 후
   test 폴더로 이동해서 아래 실행:

   npm run install:all
   npm run build
   npm start

   (또는 호스팅에서 "시작 명령"을 npm start 로 설정)

3. 접속 주소는 호스팅이 안내한 주소로 접속
   예: https://내도메인.com/test  또는
       https://내도메인.com:4000  (포트 지정인 경우)


[방법 2] 그냥 HTML/파일만 올리는 일반 웹호스팅일 때
---------------------------------------------------
Node를 실행할 수 없으면 "화면만" 볼 수 있고,
시세·채팅 같은 기능(API, WebSocket)은 동작하지 않습니다.

1. 내 컴퓨터에서 먼저 빌드:
   - game 폴더에서
   - npm run install:all
   - npm run build

2. 생성된 client/dist 폴더 **안의 파일만** 전부 선택해서
   test 폴더에 업로드 (dist 폴더 자체 말고, 그 안의 파일들)

   예: index.html, assets 폴더 등이 test 안에 보이게

3. 접속:
   https://내도메인.com/test/
   또는
   https://내도메인.com/test/index.html

   → 화면은 뜨지만 "데이터 없음" / 채팅 안 됨 (서버가 없으므로)


[정리]
------
- "전체 기능" 테스트 = Node 실행 가능한 호스팅 + 방법 1
- "화면만" 확인 = 방법 2 (client/dist 내용만 업로드)

호스팅 이름(예: 카페24, 가비아, AWS, 닷홈 등)을 알려주시면
그에 맞춰 더 구체적으로 적어드릴 수 있습니다.
